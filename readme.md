#
1. Kør `npm install` for at installere alle nødvendige pakker.
2. Opsæt .env filen med dine egne værdier ved at kopiere .env.example til .env og ændre værdierne.
3. Gå ind i database mappen og kopier alt indhold fra "alle.sql".
4. Opret forbindelse til din database og indsæt indholdet fra "alle.sql" i din database.
3. Kør `npm start` for at starte serveren.
4. Serveren vil være tilgængelig på http://localhost:8080
